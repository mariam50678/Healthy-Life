# Healthy Life 🌿

Healthy Life is a simple health and wellness website designed to help users learn about healthy nutrition, sleep, and daily wellness habits.

##  About the Project

The website provides basic health and wellness information through three main pages:

* **Home** — Introduction to the website and daily health tips.
* **Nutrition** — Information about healthy foods, their benefits, and food categories.
* **Sleep & Wellness** — A personalized daily wellness report based on the user's age, weight, height, and sleeping hours.

##  Features

###  Home Page

* Welcome message when the page loads.
* Introduction to healthy living.
* Random daily health tips.
* Navigation between website pages.

###  Nutrition Page

* Information about the importance of good nutrition.
* Healthy food table with benefits and categories.
* List of recommended healthy foods.
* Interactive prompt asking the user about their favorite healthy food.

###  Sleep & Wellness Page

* Collects the user's age, weight, height, and sleep hours.
* Provides sleep advice based on age.
* Compares weight with an estimated ideal weight based on height.
* Provides a wellness status.
* Gives an energy prediction based on sleep hours.
* Provides a nutrition recommendation related to sleep.
* Displays a personalized daily report.
